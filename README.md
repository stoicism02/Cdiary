# 小岛日记

一个 Windows 桌面任务与笔记应用，使用 WPF、.NET 10 和 SQLite。

## 运行

开发时需要 .NET 10 SDK。在项目目录执行：

```powershell
dotnet run
```

当前 Windows x64 程序位于 `dist\current\Cdiary.exe`。这是依赖 .NET 10 Desktop Runtime 的小体积版本；在其他电脑上运行前需安装该运行时。发布目录中的文件需要一起保留。后续版本统一发布到 `dist\current`。重新生成发布版：

```powershell
dotnet publish Cdiary.csproj -c Release -r win-x64 --self-contained false -o dist\current
```

支持切换日期、添加和删除任务、勾选完成、编辑任务标题与笔记、填写当天备忘，以及为任务设置一次提醒。数据自动保存在 `%LocalAppData%\Cdiary\cdiary.db`。关闭窗口时程序缩到系统托盘，继续处理提醒；通过托盘菜单可重新打开或真正退出。再次启动时会合并提示程序未运行期间错过的未完成任务提醒。

原创少女图标的源图在 `Assets\AppMascot.png`，多尺寸 Windows 图标在 `Assets\Cdiary.ico`，用于程序文件、任务栏窗口和托盘。

选中任务后点击“打开便签”，可以把这项任务的标题和笔记放在独立小窗口中编辑。每项任务只会打开一个便签；便签可拖动、调整大小、切换置顶，主窗口缩到托盘后仍可使用。修改自动保存，并与主界面的笔记同步。

在左侧选中日期后点击“弹出当日待办”，会打开该日的任务清单便签。清单支持置顶和勾选完成；双击清单中的任务即可打开它专属的笔记便签。同一天只会打开一个清单窗口，主窗口缩到托盘后清单仍可使用。

主窗口最左侧的导航栏可切换“待办”“日历”“搜索”“已完成”和“设置”。勾选完成的任务会从当天待办清单和当日便签中移走，在“已完成”页按完成日期分组。可以按全部日期、今天或近 7 天查看，并将任务恢复到原日期的待办清单。每日进度仍包含已完成的任务。搜索支持任务标题、任务笔记与每日备忘；输入关键词后按回车或点击搜索，点击结果会回到对应日期和任务或备忘。

选中今天时，待办清单上方会出现可折叠的“之前没做完”，汇总已经存在的过去未完成任务。点击标题可回到原日期，直接勾选可完成并移入“已完成”。窗口较矮时默认收起任务条，仍可手动展开。这些旧任务保留原日期，未安排到今天时不计入今日清单，也不会补生成过去的重复任务。只有设置了截止日期且已超过该日期，才称为逾期。

日历页展示整月待办，可切换月份、回到今天、打开某一天或某个任务，并在当前选中的日期添加任务。任务较多时显示剩余数量。未来重复任务会以预览纸条显示；翻阅月份不会批量创建任务，打开具体日期时才生成该天实例。

任务详情里的“设置重复”支持每天或每周指定日期；只有选择每周时才显示星期选项。提醒时间用小时、分钟下拉框选择，分钟以 5 分钟为间隔。后续任务按需生成，笔记初始为空，每天的完成状态和笔记独立；修改规则只影响尚未生成的任务。删掉单日任务后，当天不会重新生成；停止重复会保留已有记录。

设置页可选择登录 Windows 后自动在后台启动，默认关闭。后台启动时只显示托盘图标，需要时可从托盘打开主窗口。提醒依赖程序运行。Windows 的通知设置或免打扰模式可能影响提醒展示。

## 跨日任务与持续推进

在任务详情的“日期与推进”，或任务行、任务便签的“⋯”菜单中，设置安排日期、可选的截止日期与“持续推进”。持续推进默认关闭；开启后，从安排日期起，每天沿用同一个任务，直到整项完成。任务笔记、附件和专注历史始终关联原任务。重复任务暂不能同时开启持续推进，重复实例的安排日期仍由规则控制。

“今天先到这里”会先结算该任务正在进行的专注，再把任务收起到“今日已推进”（默认折叠）；“继续处理”可恢复，重新开始专注也会恢复今日清单。开启持续推进的任务第二天重新出现。勾选完成表示整件事结束，收纳到已完成页。主窗口与多个日期便签共享任务状态，但各自独立过滤当天的清单。

月历以实际发生的日期记录安排、手动推进与专注投入：绿色代表实际完成日，青色代表推进，红色表示当日已超过明确的截止日期，其他为安排。之后完成任务不会把以前的推进日全部改绿；离线期间不补造推进。改期保留已经发生的投入与历史记录。专注栏可查看今日投入及任务累计时长，休息与离线时间不计入。

首次升级在数据库旁生成 `cdiary.db.before-multiday.bak` 一致性备份，以事务添加日期与每日状态表。旧任务的持续推进默认关闭，不推断截止日期。后台复用原有午夜刷新，不新增轮询计时器。提醒仍是原有的一次提醒，不随持续推进每天重复触发。

跨日数据、迁移、计时结算与多窗口检查：`dotnet run --project tests/MultiDay/MultiDay.csproj`（仅使用临时数据库，不显示窗口）。

## 任务专注

侧栏“专注”提供番茄钟和正计时，支持暂停、继续、结束及休息。任务详情中的“开始专注”会定位到该任务的计时设置；便签中的“开始专注”直接按上次保存的模式和时长启动当前任务，不跳转主窗口。便签运行时显示紧凑计时条，关闭便签后继续计时。

默认 25 分钟专注、5 分钟短休息，每四个完整番茄建议 15 分钟长休息。时长按 5 分钟选择，记住上次模式和专注时长。专注设置可从专注页底部或设置页进入。专注到时保存并提醒，不自动开始下一轮，不自动完成任务。

专注记录保存在本地 SQLite；提前结束也计入投入时间，暂停和休息不计入。今日统计包含当前会话（最多十秒刷新一次），跨日按本地日期拆分。今日投入按任务分配时间：多个任务共用一根分色条，列出各任务时长和今日占比；只有一个任务时只显示名称与时长。番茄钟仅在当前计时区显示本轮进度，正计时不显示完成百分比。任务完成或删除会结算计时，历史保留名称快照。全局最多一个未结束会话。

锁屏和睡眠暂停，退出保存；异常重启只恢复最后检查点并暂停，最多丢失最后约 30 秒尚未保存的时间，不累计离线时间。未打开计时界面时不执行每秒绘制。托盘可打开专注或暂停/继续；提示音可关闭，系统通知仍受 Windows 通知设置影响。

验证：`dotnet run --project tests/Focus/Focus.csproj -c Release` 与 `dotnet run --project tests/FocusUI/FocusUI.csproj -c Release`。使用临时数据库和不可见窗口。

## Markdown 任务笔记

主界面只展示轻量的原生 Markdown 预览，不启动浏览器编辑器。点击“打开便签”进入独立任务便签，直接使用所见即所得编辑器书写。便签不先显示阅读页，编辑器就绪后自动获得输入光标，无需再次点击正文；若已切换到其他窗口，则不抢回焦点。主页和便签都不再显示“文档 / 源码 / 预览 / 并排”模式切换条。

独立便签没有“源码”和“完成”按钮。输入自动保存，光标离开编辑区或切换到其他窗口时立即补存；中文组词未确认时，等确认后再提交。**Ctrl+S** 仍可手动补存，但不再切成只读。失焦保留编辑器和撤销历史，关闭、隐藏或切换任务时保存并释放。保存失败保留输入并显示提示。

文档模式提供紧凑工具栏、选中文字后的浮动格式条，以及空段落输入 `/` 打开的插入菜单。支持标题、粗体、斜体、列表、引用、网页链接、行内代码、代码块、表格和可勾选的笔记清单；笔记清单不会改变外层任务的完成状态。输入 `##` 后按空格可转换为标题，列表回车自动续写。`Ctrl+B` 加粗、`Ctrl+I` 斜体、`Ctrl+K` 插入链接，`Ctrl+Z / Ctrl+Y` 撤销和重做。文档内按住 Ctrl 点击网页链接，通过默认浏览器打开。

浏览器不可用或遇到不支持的文档内容时，便签自动回退到原生 Markdown 源码编辑，仍自动保存。原生预览里的代码块自动换行；可见预览在输入停止 300 ms 后刷新，隐藏时停止渲染，文档模式不会同时刷新隐藏的原生预览。

文档和源码编辑均支持以下快捷键：

| 快捷键 | 操作 |
| --- | --- |
| Ctrl+B / Ctrl+I | 加粗 / 斜体 |
| Ctrl+K | 插入链接 |
| Ctrl+1～6 | 将当前段落设为一至六级标题 |
| Ctrl+0 | 恢复正文 |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做 |

文档模式的标题快捷键保留段落文字，代码块和表格内不转换标题；输入法组词期间不拦截。源码模式选中多行时会同时转换这些行，并替换已有标题级别。

笔记仍以 Markdown 保存在原 SQLite 字段中。仅打开旧笔记不会改写原文，首次文档编辑前保留一份原文备份；实际编辑后由编辑器生成 Markdown。文档输入即时同步任务对象，500 ms 后写入数据库；结束编辑和退出程序会先提交最后输入。若另一窗口已更新同一份笔记，过期输入会保留为找回副本，不覆盖新内容。可通过“更多 → 备份 / 找回”导出这些副本。完成编辑释放浏览器时，文档模式的撤销历史结束；源码模式仍保留最近 20 项编辑状态。

原生部分使用 [AvalonEdit](https://github.com/icsharpcode/AvalonEdit) 6.3.1.120 和 [MdXaml](https://github.com/whistyun/MdXaml) 1.27.0；文档模式使用 [Vditor](https://github.com/Vanessa219/vditor) 4.0.0 和 WebView2 SDK 1.0.4258.31。所有编辑资源随程序本地提供，不使用在线 CDN。文档模式需要已安装的 Microsoft Edge WebView2 Runtime；不可用时回退到原生源码编辑。许可说明见 `MARKDOWN-NOTICES.md`。

当前不包含通用 `.md` 导入导出、块拖拽或协作；含公式、图表的笔记建议使用源码编辑，检测到公式块或已知图表代码块时会自动切换。当天备忘仍为轻量纯文本。

笔记展示、失焦保存及兼容模式验证：`dotnet run --project tests\Transitions\Transitions.csproj -c Release -- preview-transitions`。覆盖主页只展示、便签直接书写、失焦保存、输入法延迟补存、保存失败、隐藏释放，以及旧模式交接兼容性；使用不可见窗口和临时数据库。

### 笔记目录

点击笔记工具栏的“目录”，可按层级浏览一至六级标题，点击标题跳转，当前阅读章节随滚动高亮。同名标题分别定位；代码块里的井号不作为标题。目录默认收起，无标题时显示添加提示。

笔记区域宽度达到 720 DIP 时，目录显示在右侧约 160 DIP 的窄栏；较窄时显示浮层，选择章节后自动收起，可点击外部或关闭按钮收起。这里按笔记区域宽度判断，不是整个窗口宽度。打开目录后，“并排”仍需正文剩余宽度达到 640 DIP。

文档编辑、轻量预览和源码均可使用目录；源码跳转会定位光标到标题行。目录导航不会改写笔记，预览目录不加载 WebView2。停止输入约 300 ms 后更新标题，中文组词确认后再刷新；收起或隐藏时停止目录更新，不增加持续轮询。

目录验证（后台不可见窗口、临时数据库）：

```powershell
dotnet run --project tests\Outline\Outline.csproj -c Release -- preview-outline
```

### 笔记图片

文档和源码模式支持 `Ctrl+V` 粘贴图片、拖入本地图片，也可通过菜单选择。文档入口在“更多 → 图片”或空段落 `/ → 图片`；源码入口在 `Aa ＋ → 图片`。一次插入一张 PNG 或 JPEG，单张最多 20 MB、4000 万像素。普通文字仍按原方式粘贴。

图片先独立保存，再在光标位置插入 `![图片](attachments/图片ID.png)` 引用。原图位于 `%LocalAppData%\Cdiary\Attachments\originals`，预览图位于同级 `previews`；索引保存在日记数据库中。JPEG 引用使用 `.jpg` 后缀。图片按文件内容去重，不会引用截图箱的临时路径，截图到期或外部原图删除后仍可查看。备份整个日记时应同时复制数据库与 `Attachments` 目录。

正文按可用宽度显示最长边不超过 1024 像素的预览图；原生轻量预览在图片接近可见区域时加载，不启动浏览器。双击图片打开原图查看器，可缩放、拖动、复制和另存为。只在查看原图时读取完整图片。

图片导入时继续修改正文、切换任务、结束编辑或撤销，可能取消该次插入并提示重试，避免插错位置；原有文字保持。导入失败不会插入失效引用。完成保存但尚未插入的图片按未使用附件管理。

从正文删除图片不会立即删除文件，撤销可恢复。设置页“笔记图片”显示占用和清理入口，确认后永久清理未使用图片。清理会保留正文、备份与找回副本引用的图片；本次运行中导入或编辑过的图片也保留，供撤销使用，重启后可重新检查。附件不会被截图箱的定时清理删除。

附件验证（临时数据，不访问系统剪贴板、不显示窗口）：

```powershell
dotnet run --project tests\Attachments\Attachments.csproj -c Release -- preview-attachments
```

Markdown 验证与预览图生成（临时数据库、后台渲染，不显示窗口）：

```powershell
dotnet run --project tests\Markdown\Markdown.csproj -c Release -- preview-markdown
dotnet run --project tests\DocumentEditor\DocumentEditor.csproj -c Release -- preview-document
```

## 截图箱

默认按 `Ctrl + Alt + S` 框选截图，松开鼠标后自动复制图片并暂存，`Esc` 或右键取消。也可以从侧栏“截图”页或托盘菜单点“截一张”。全局快捷键依赖程序在后台运行；可在设置页更换、关闭，快捷键冲突时会提示。截图不会自动打开主窗口。

截图箱按日期展示最近的缩略图，双击打开无系统标题栏的原图预览，支持适应窗口、100% 显示、滚轮缩放、拖动查看、复制和另存为。点击卡片选择，Ctrl / Shift 或复选框多选，可批量另存和删除。删除需要确认；另存的图片不受自动清理影响。

默认保留 **1 个自然日**，每天本地时间 00:00 清理之前的截图。例如 10 月 1 日 23:58 的截图在 10 月 2 日 00:00 到期。设置为 3 天时，10 月 1 日的截图在 10 月 4 日零点到期。支持 1–365 天；缩短保留天数若会立即清理已有图片，会先显示数量并要求确认。启动、唤醒和系统时间改变后会补清理，文件被占用时稍后重试。

默认容量上限为 500 MB（包括原图和缩略图），可设为 10–10240 MB。到达上限后仍会复制，但暂停暂存并提示，不提前删掉尚未到期的图片。剪贴板被占用时会短暂重试；复制和存储分别报告结果。再次复制其他内容会正常替换剪贴板，可以回截图箱重新复制旧图。

图片与独立的索引库位于 `%LocalAppData%\Cdiary\Screenshots`，不进入 Git 仓库或日记数据库。缩略图按可见行加载，原图仅预览时加载；已打开的预览保留内存快照，文件到期后仍可另存。自动清理不影响外部导出、已粘贴到其他软件的内容或 Windows 剪贴板历史。

区域截图采用 Windows 屏幕复制与物理像素坐标，支持虚拟桌面负坐标；多显示器混合缩放的真实框选、特殊 HDR 显示和目标应用粘贴兼容性仍需在对应设备上验收。首版不包含标注、OCR 和滚动长截图。

## 简约任务便签

任务便签使用雾白底色、深灰正文和精简标题栏。右上角“外观”可选择或移除 PNG/JPEG/BMP 背景，分别调节背景不透明度（10%～100%）与图片浓度；文字、按钮和编辑器始终保持不透明。背景图片居中裁切填充，外观设置全局共享，已打开的任务便签自动同步；窗口是否置顶仍分别控制。

背景副本与设置保存在数据库旁的 `NoteAppearance/global/`，独立于截图箱清理及笔记附件。单张导入上限 20 MB、8000 万像素，最长边缩至 1600 像素，不放大小图；原图片移动或删除不会影响已导入的背景。首次升级优先迁移最近导入且仍存在的旧任务背景，保留原文件。

透明便签使用 WebView2 合成控件，会比普通编辑器增加渲染开销；主页仍保持轻量预览。合成与普通编辑器使用独立的运行时缓存，避免同时打开时的控制器冲突。构建目标为 Windows 10 1809 或更新版本。

外观与透明窗口验证：`dotnet run --project tests/NoteAppearance/NoteAppearance.csproj`。透明编辑器完整验证：设置环境变量 `CDIARY_TEST_MINIMAL=1` 后运行 `tests/DocumentEditor`；验证窗口位于屏幕外且不激活。

## 开发预览与样式热加载

在项目目录执行下面的命令，会从 `bin\Debug` 启动独立的开发预览，可与 `dist\current` 的日常版本同时运行：

```powershell
.\dev-preview.ps1
```

开发预览使用 `%LocalAppData%\Cdiary\DevelopmentPreview` 中的示例数据，有独立的单实例标识和托盘入口。不发送任务提醒、不注册全局截图快捷键、不修改开机自启设置；关闭窗口仍会留在开发预览托盘，选择“退出”才结束。需要后台启动时可传 `-Background`。

保持预览运行，修改 `Styles\SharedStyles.xaml` 并保存，约 300 ms 后会重新加载样式。编辑器临时占用或写入不完整时会短暂重试；XAML 有误、缺少必需资源或控件类型不兼容时保留上一版。顶部状态区会提示结果，悬停查看错误详情，也可以从开发预览托盘选择“重新加载样式”。

| 要调整的外观 | 共享资源 |
| --- | --- |
| 主色、纸色、文字色 | `Accent`、`WindowSurface`、`PaperSurface`、`Ink`、`TextInk` 等画刷 |
| 常规、主要和图标按钮 | `Pill`、`PrimaryPill`、`IconPill`、`DangerPill` |
| 两种便签的关闭按钮 | `NoteCloseButton`（默认 30 × 30）和 `NoteButton` 模板 |
| 便签标题、置顶图标 | `NoteTitle`、`PinToggle` |
| 输入框 | `PaperInput`、`NoteInput`、`CompactInput` |

样式通过 `DynamicResource` 作用到已有控件，不重建窗口，不替换任务对象。新增窗口也会使用最新的有效样式。请保留资源键和控件类型；不要在共享文件里另加 `MergedDictionaries`。控件自身明确设置的属性优先于样式，调整这类属性或修改窗口布局、事件和 C# 逻辑仍需重新构建并重启开发预览。

正常启动的正式版只读取程序内嵌样式，不监听外部文件。此功能不会让已经运行的旧版程序获得热加载能力，也不替换运行中的 DLL。开发预览的样式确认后，下次正式发布会将样式编入程序。

等价的启动命令：

```powershell
dotnet run --project Cdiary.csproj -c Debug -- --dev --styles D:\Cdiary\Styles\SharedStyles.xaml
```

## 窗口布局

月历默认显示全部任务，已完成为绿、今日待办为橙、逾期为红、未来计划为蓝灰，并配合状态符号。可筛选全部/未完成/已完成；日期右上角是完成数/总数（包含重复预览）。点击“还有 N 项”查看该日清单，返回按钮或 Esc 收起。已完成任务仍可打开笔记并查看完成时间，补做过去任务不会改变其计划日期。

拖动窗口边缘即可切换布局：小于 1000 DIP 时任务和笔记分开显示，点任务进入详情、点击“待办”或按 Esc 返回；1000～1399 使用双栏，1400 起展开独立日期栏。最小窗口为 760 × 580，字体与按钮保持正常大小。截图箱随宽度切换 2～5 列，设置页和便签也会调整排版。

切换布局保留任务、笔记输入和图片选择状态，不添加持续轮询或新 UI 依赖。窗口结构与事件代码仍需编译后重启；共享样式继续支持开发模式热加载。

响应式检查（后台测量和渲染，不显示窗口）：

```powershell
dotnet run --project tests\Responsive\Responsive.csproj -c Release
dotnet run --project tests\Preview\Preview.csproj -c Release -- preview-responsive
```
