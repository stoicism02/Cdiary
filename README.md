# 小岛日记

一个 Windows 桌面任务与笔记应用，使用 WPF、.NET 10 和 SQLite。

## 运行

开发时需要 .NET 10 SDK。在项目目录执行：

```powershell
dotnet run
```

当前 Windows x64 程序位于 `dist\win-x64-repeat-picker\Cdiary.exe`。这是依赖 .NET 10 Desktop Runtime 的小体积版本；在其他电脑上运行前需安装该运行时。发布目录中的文件需要一起保留。重新生成发布版：

```powershell
dotnet publish Cdiary.csproj -c Release -r win-x64 --self-contained false -o dist\win-x64-repeat-picker
```

支持切换日期、添加和删除任务、勾选完成、编辑任务标题与笔记、填写当天备忘，以及为任务设置一次提醒。数据自动保存在 `%LocalAppData%\Cdiary\cdiary.db`。关闭窗口时程序缩到系统托盘，继续处理提醒；通过托盘菜单可重新打开或真正退出。再次启动时会合并提示程序未运行期间错过的未完成任务提醒。

选中任务后点击“弹出便签”，可以把这项任务的标题和笔记放在独立小窗口中编辑。每项任务只会打开一个便签；便签可拖动、调整大小、切换置顶，主窗口缩到托盘后仍可使用。修改自动保存，并与主界面的笔记同步。

在左侧选中日期后点击“弹出当日待办”，会打开该日的任务清单便签。清单支持置顶和勾选完成；双击清单中的任务即可打开它专属的笔记便签。同一天只会打开一个清单窗口，主窗口缩到托盘后清单仍可使用。

主窗口最左侧的导航栏可切换“待办”“日历”“搜索”“已完成”和“设置”。勾选完成的任务会从当天待办清单和当日便签中移走，在“已完成”页按完成日期分组。可以按全部日期、今天或近 7 天查看，并将任务恢复到原日期的待办清单。每日进度仍包含已完成的任务。搜索支持任务标题、任务笔记与每日备忘；输入关键词后按回车或点击搜索，点击结果会回到对应日期和任务或备忘。

日历页展示整月待办，可切换月份、回到今天、打开某一天或某个任务，并在当前选中的日期添加任务。任务较多时显示剩余数量。未来重复任务会以预览纸条显示；翻阅月份不会批量创建任务，打开具体日期时才生成该天实例。

任务详情里的“设置重复”支持每天或每周指定日期；只有选择每周时才显示星期选项。提醒时间用小时、分钟下拉框选择。后续任务按需生成，笔记初始为空，每天的完成状态和笔记独立；修改规则只影响尚未生成的任务。删掉单日任务后，当天不会重新生成；停止重复会保留已有记录。

设置页可选择登录 Windows 后自动在后台启动，默认关闭。后台启动时只显示托盘图标，需要时可从托盘打开主窗口。提醒依赖程序运行。Windows 的通知设置或免打扰模式可能影响提醒展示。

当前发布目录约 2.4 MiB。开发机的一次空闲采样中，3 秒内 CPU 时间增加 0 秒、私有内存约 155 MiB；实际占用因系统和使用情况而异。

## 验证

```powershell
dotnet run --project tests\Smoke\Smoke.csproj -c Release
```

此命令使用独立的临时数据库检查任务、备忘、提醒状态与到点触发，不会修改正式数据或开机自启设置。

界面参考 [animal-island-ui](https://github.com/guokaigdg/animal-island-ui) 的设计语言；视觉规则见 [DESIGN.md](DESIGN.md)。
