# A · 轻岛

**亲和、清楚、每天容易开始。** 保留小岛日记的轻松气质，把可爱集中在少量柔软边角与操作回应上。主角是任务内容，绿色只提示当前选择与主操作。

## 视觉与布局

| 设计值 | 选择 |
| --- | --- |
| 工作区 / 内容 | 雾绿 `#F2F7F5` / 白 `#FFFFFF` |
| 正文 / 辅助字 | `#263D38` / `#60736C` |
| 强调 / 警示 | 深青绿 `#217D6F` / 陶红 `#B54A3B` |
| 字体 | Segoe UI Variable / Microsoft YaHei UI；正文 14、辅助 12、标题 22 DIP |
| 几何 | 4 DIP 间距基准；按钮高 34、普通任务行 52；控件圆角 6、弹层 10；容器不叠卡片 |
| 动效 | 按下 80 ms 轻微压缩到 0.98，松开 140 ms；收起与展开 140 ms；无循环动效 |

Segoe UI Variable 不可用时使用 Segoe UI；中文使用本机微软雅黑，不下载字体。底色不做渐变。完成、推进、逾期同时有文字与符号，彩色不承担唯一含义。

```text
┌ 小岛日记       今天，10 月 13 日                    弹出清单 ┐
│ 今天          周一  [周二]  周三 …                           │
│ 月历          ┌ 今日待办  4 项 ─────────┬ 任务阅读 ────────┐ │
│ 专注          │ ＋ 添加任务             │ 任务标题         │ │
│ 搜索          │ □ 复习 RocketMQ   持续  │ 日期 / 截止      │ │
│ 截图箱        │ □ 整理项目笔记         │ 阅读正文         │ │
│ 已完成        │ □ …                    │                  │ │
│               │ ▸ 之前未完成          │ 在便签中编辑     │ │
│ 设置          │ ▸ 今日已推进          │                  │ │
│               │ 当日备忘（轻量展开）  │                  │ │
└───────────────┴────────────────────────┴──────────────────┘
```

功能侧栏 148～164 DIP，始终有短文字标签；当前项用细色条与浅底标识。页面只有一层主要分隔，不为标题、清单、备忘再套大圆角盒。日期导航只占一行，宽屏也不自动增加一整根日期柱。

标准宽度下清单约 55%、阅读约 45%，详情最少 300 DIP。低于 1100 DIP 时进入单栏清单，选任务打开可返回的详情页；1400 以上阅读宽度受限，避免正文行太长。760 × 580 时至少看到 4 条普通任务，备忘折叠为摘要；这是后续验收目标。

## 页面与组件

| 页面 | 组织方式与交互 |
| --- | --- |
| 今日 | 快速输入置顶；普通待办与持续任务共用任务行，次行仅在有日期信息时出现。之前未完成和今日已推进使用轻量折叠标题 |
| 任务详情 | 上方标题及可编辑属性，正文只读；“在便签中编辑”是明确主入口。提醒、重复、安排保持原有业务弹窗和规则，视觉统一 |
| 月历 | 7 列平整网格、每格轻背景；只为选中日加明显边界。窄屏上半月格、下半选中日清单，完整标题在清单阅读 |
| 专注 | 任务名、时间、暂停 / 结束作为主要区域；统计在侧边，窄屏下移。本轮进度与今日时间分配分别说明 |
| 搜索 | 导航内文字入口；独立搜索页，关键词与结果摘要有明确层级，结果仍按既有接口跳转 |
| 完成 | 按完成日的紧凑列表，恢复放在每行末端；完成日期与原安排日期不混用 |
| 截图箱 | 缩略图边界缩小，时间作为主标签；到期提示在列表头和选中项明细中可见。选中后显示批量操作，避免始终展示禁用按钮 |
| 设置 | 左侧设置分组、右侧紧凑字段；相关说明贴近控件，保存反馈保留在本组。仅重排已有设置 |
| 当日便签 | 32 DIP 标题栏、单列 40～48 DIP 任务行、默认折叠的已推进区。置顶与关闭始终固定右上角 |
| 任务便签 | 用户已确认保持现状：外观、布局、编辑模式、保存、置顶、全局背景与透明度均不修改，不继承本案新主题 |

组件体系：Primary / Secondary / Quiet / Danger 四种按钮；TaskRow、DateStrip、StatusLabel、InlineNotice、PropertyRow、StickyChrome、NoteToolbar 八类共享组件。旧胶囊按钮只保留在确有选择意义的分段控件中。

## 反馈与可访问性

完成后移至完成记录，并给出短暂“已完成 · 恢复待办”提示；该恢复调用既有恢复能力，不意味着通用撤销历史。今日收起显示“今天已收起，明天继续”，关闭持续推进时改为“今天已收起”，避免承诺自动进入明日。

任务便签沿用现有交互与样式。主窗口键盘焦点用 2 DIP 深绿色细框，支持系统减少动画设置；这些样式不覆盖便签。

## 适用与取舍

适合任务安排、零碎笔记和桌面常驻的混合使用。用户从现有版迁移最轻松，WPF 与现有共享资源的适配也最直接。美观依靠比例、文字和少量反馈，不靠插画填充。

设计判断：美观 4.5/5、可用性 4.5/5、维护便利 4.5/5、业务适配 5/5。风险是过度收敛后可能显得普通；通过小岛品牌字标、细节曲率和温和反馈保持辨识度。不要再给每一块内容套卡片，否则会回到当前问题。

评审时重点看：清单是否足够轻松，窄屏进入详情是否自然，打开现有任务便签的路径是否顺畅。
