# B · 纸页

**一天是一页，任务与记录自然相连。** 用日期组织工作，强化当天备忘与回顾。桌面像一本打开的记录簿，单个任务可以延续到多天，但始终指向同一份笔记。

## 视觉与布局

| 设计值 | 选择 |
| --- | --- |
| 桌面 / 纸面 | `#F7F5F0` / `#FFFEFA` |
| 正文 / 辅助字 | `#333632` / `#616759` |
| 强调 / 链接 | 橄榄绿 `#5F6E43` / 石蓝 `#527085` |
| 字体 | 日页日期用 Georgia 数字、可选宋体标题；控件与正文仍为微软雅黑 / Segoe UI。正文 15、标题 23、日期 42 DIP |
| 几何 | 宽松的纸页边距 24～32，文本任务行 44；输入框圆角 4，弹层 8；分隔仅表达内容结构 |
| 动效 | 日期切换 120 ms 轻淡入；折叠 120 ms；无翻页 3D、纸张卷曲或持续阴影动画 |

中文宋体仅用于短标题，长篇笔记仍使用易读无衬线。日期是唯一明显的大字元素，不增加无意义编号、装饰英文或纸纹图片。可爱来自自然的日常文案与纸张比例，保留一点个人记录的温度。

```text
┌ 小岛日记                 日页   月历   专注   资料       设置 ┐
│ 十月 · 日期索引      ┌─────────────────────────────────────┐│
│ 周一 12             │ 13  星期二                 弹出清单 ││
│ 周二 13  ← 今天     │ 今日安排                              ││
│ 周三 14             │ □ 复习 RocketMQ       持续推进       ││
│ …                   │ □ 整理项目笔记                       ││
│ 回到今天            │ ＋ 添加一项                           ││
│                     │ ▸ 之前未完成   ▸ 今日已推进          ││
│ 搜索记录            │ 当日备忘                              ││
│                     │ 今天先理解消息可靠性的完整链路……      ││
│                     │ [选中任务的阅读摘要] → 在便签中编辑   ││
└─────────────────────┴─────────────────────────────────────┘│
```

顶部承载全局模式，左侧承载当前月份的日期索引。主纸面把任务与当日备忘放在一个阅读流中，备忘不再用高饱和底色。选中任务的只读摘要展开在任务下方；较宽窗口可放在侧边纸栏。与 A 的永久清单 / 详情双栏不同，默认一次读完整的一天。

“资料”只是现有搜索、截图箱、已完成的导航分组，不创建新的文件库或笔记实体。资料页有固定二级导航，最多两步进入；常用搜索也保留在日期索引底部。若用户频繁在截图与任务间切换，这多一层导航是本案的主要代价。

低于 1100 DIP 隐藏左日期索引，改为标题中的日期选择；760 DIP 仍保留日页和完整任务行。宽屏纸面最大 920 DIP，可选旁边 320 DIP 任务阅读；不将普通文字拉满屏幕。

## 页面与组件

| 页面 | 组织方式与交互 |
| --- | --- |
| 日页 | 任务在上、备忘在下，按内容自然占高；今日已推进在任务段底部。跨日任务附开始 / 截止文字，不复制正文 |
| 任务阅读 | 以可收起的阅读片段附在任务旁，默认显示标题与正文摘要；编辑仍进入独立便签。长文展开为当前页的阅读栏 |
| 月历 | 整月网格像索引页，优先显示状态数量和少量标题；右侧或下方为选中日“任务与记录”明细，不新增日程时段 |
| 专注 | 纸面中的单个计时区域，周围留出空间；当日投入和已有专注历史按时间顺序排在下方，无虚构任务开始时刻 |
| 搜索 | 资料下的全文检索列表，结果显示日期、任务名、命中摘要；仅使用现有搜索能力 |
| 已完成 | 按完成日期排成记录簿，原安排日期弱化但可查看，恢复入口保持文字可见 |
| 截图箱 | 资料中的缩略图接触表；选中图片后展示原尺寸、清理时间和另存。纸面感来自间距，不给每张图加厚相框 |
| 设置 | 朴素的分组表单；自然日保留天数与快捷键在同组，当前生效值直接可读 |
| 当日便签 | 便签标题突出具体日期，单列清单与日页一致；双击任务打开对应笔记 |
| 任务便签 | 用户已确认保持现有外观与模式；不套用纸页主题。直接编辑、自动保存、置顶、全局背景与透明度原样保留 |

组件体系：JournalHeader、DateIndex、TaskLine、MemoSection、InlineReading、ArchiveEntry、ContactSheet、PlainPropertySheet。按钮以文字和少量描边为主；选中任务使用左侧短标记，只有必要操作使用实底。

## 反馈与可访问性

任务完成从日页待办移走，并提示“已记录到 10 月 13 日完成”；今日收起留在折叠段中，不表现为文字划掉。日期切换仍保存日备忘输入，保持光标与滚动的可预期行为。

所有状态用清楚的文字：安排、推进、完成、逾期。键盘焦点使用石蓝细框；静态纸面不制造无限动画。输入区域不只靠下划线区别，聚焦时有完整边框与标签，避免阅读内容与可编辑内容混淆。

## 适用与取舍

适合看重每天记录、回顾和轻度计划的人，尤其是任务和每日备忘使用频率接近的场景。该方向最能体现“日记”名称，也能让长期任务自然出现在连续日页中。

设计判断：美观 4.5/5、可用性 4/5、维护便利 3.5/5、业务适配 4/5。主要成本来自日期导航与功能导航重新分工，以及任务摘要的展开 / 收起状态。它不应演变成含子文档、标签库、项目空间的知识库；现有业务并不支持这些概念。

评审时重点看：日页是否符合你实际工作顺序，截图和搜索的额外导航是否能接受，每日备忘是否值得占更重要的位置。
