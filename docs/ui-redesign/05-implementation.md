## 已实施

- 主窗口限定使用 `Styles/LightIsland.xaml`：雾绿底色、白色输入区、深青绿操作按钮、紧凑圆角和清晰文字。
- 148 DIP 文字导航；窄窗口缩为 112 DIP。设置入口固定在底部。
- 日期导航始终横向排列，宽屏不再增加独立日期柱。
- 快速添加位于任务上方；任务行约 52 DIP；之前未完成默认收起。
- 当日备忘可展开，在矮窗口默认收起；任务安排、提醒、重复与删除收入阅读区的可展开区域。
- 标准与宽窗口为清单 / 只读笔记双栏；低于 1100 DIP 切换为清单 / 详情，返回时保留任务与输入。
- 完成后显示可恢复提示，复用已有恢复待办流程。没有新增撤销数据库或变更完成规则。
- 月历改为平整网格，减少窄窗口最低高度，按实际高度限制条目数，保留完整日期清单入口。
- 专注页、搜索、完成记录、截图箱与设置接入主窗口视觉体系。截图批量操作只在选中后显示；设置提供分组定位与紧凑字段。

实际图见 [implemented.html](implemented.html)。生产保留了现有月历的当天清单弹层，以及日期 / 重复设置对话框的行为；没有把 HTML 原型中的示例状态或简化表单替换到业务中。当日待办浮窗也保留现有实现。

`TaskNoteWindow`、`NoteAppearance`、`EditorWeb`、`DocumentNoteHost`、`MarkdownNoteView` 源码及 `SharedStyles.xaml` 均未改动。主窗口内的只读笔记实例单独加载新资源，任务便签不继承这些资源。
