# C · 专注台

**把当前任务、资料和计时放进稳定的工作区。** 面向连续学习与工作，减少大幅页面跳转。使用低饱和深蓝灰与明确的列关系，信息更密集，但保留足够行高和文字对比。

## 视觉与布局

| 设计值 | 选择 |
| --- | --- |
| 工作台 / 次级面板 | `#202936` / `#29343F` |
| 正文 / 辅助字 | `#E3EBEC` / `#A6B5BC` |
| 强调 / 提醒 | 柔和青绿 `#81BFB6` / 琥珀 `#CFA965` |
| 字体 | Segoe UI Variable / Microsoft YaHei UI；正文 14、辅助 12、标题 20；计时数字 Consolas 44～56 DIP |
| 几何 | 顶栏 42、页面工具栏 44、任务行 40～46；控件圆角 4、浮层 8；按列组织，避免嵌套容器 |
| 动效 | 状态颜色 100 ms 过渡，面板 120 ms 显隐；计时数字不滚动、不呼吸；支持减少动画 |

这是适合持续注视的工作台方向，不使用纯黑加荧光色，也不模拟命令终端。淡色主按钮配深色文字，避免在浅青底上使用白色小字。高密度通过减少无效边距获得，不通过缩小字号。

```text
┌ 小岛日记   今天  月历  专注  搜索  截图箱  完成         设置 ┐
│ 10 月 13 日      ＋ 添加任务                     弹出清单   │
├ 今日任务 ─────────┬ 所选任务 · 阅读 ──────────┬ 当前专注 ──┤
│ □ 复习 RocketMQ   │ 消息可靠性                 │ 20:00      │
│   持续 · 周五截止 │ 生产者、Broker、消费者…    │ 暂停 结束  │
│ □ 整理项目笔记    │                            │ 今日投入   │
│ □ …               │                            │ 42 分      │
│ ▸ 今日已推进      │                            │            │
│ ▸ 之前未完成      │                            │            │
├───────────────────┤ 在便签中编辑               │            │
│ 当日备忘摘要      │ 属性：日期 / 提醒 / 重复    │            │
└───────────────────┴────────────────────────────┴────────────┘
```

采用顶部工作区导航，释放左侧水平空间。主内容是一组稳定分栏：任务、阅读、专注。专注侧栏显示已有 FocusService 的当前会话和当日数据，无需增加后台服务；未开始时显示任务与“开始专注”，不放一个无意义的巨大 00:00。

专注区域始终表达“目前计时的任务”，它可能与当前阅读任务不同；两者必须各自显示任务名，不能因选择另一任务而静默切换计时。切换专注沿用现有结束确认。

1280 DIP 以上显示三栏；1000～1279 将专注收成底部状态条；760～999 显示任务列表或阅读详情，计时条保持可见。底条不遮住内容，并保留足够窗口拖动区。月历和截图箱可以占满工作区。

## 页面与组件

| 页面 | 组织方式与交互 |
| --- | --- |
| 今日 | 行式任务，主标题与截止日期对齐；持续推进用简短文字。完成动作与更多菜单固定列宽，长标题省略并可展开 |
| 任务阅读 | 文档预览为中间主要区域，低频属性在可收起段中；全尺寸编辑仍在任务便签中 |
| 月历 | 深色中性网格，状态采用小色标 + 文本；选中日清单为固定明细区。窄屏优先完整标题，不把所有月格压成短字符 |
| 专注 | 专注页提供模式与参数配置、完整历史；工作区侧栏和便签只提供当前会话控制，共享同一状态源 |
| 搜索 | 全宽结果列表，日期、标题、摘要分列。保留常驻文字入口，不用只有快捷键才能发现的命令框 |
| 已完成 | 紧凑日期分组列表，恢复操作放行末；与今日的完成 checkbox 外观有明确差别 |
| 截图箱 | 图片占主要面积，缩略图外框极轻，选择状态明显。详情与批量操作在稳定工具区显示，仍使用现有虚拟化加载 |
| 设置 | 分类列表 + 紧凑属性表，深色原生弹窗与网页弹层统一。高对比模式另行验证，不等同于深色主题 |
| 当日便签 | 低装饰小窗口，标题只留日期、置顶、关闭；任务行 40 DIP 左右，正文区域优先 |
| 任务便签 | 用户已确认保持现有外观与模式；不随主窗口变为深色。直接编辑、自动保存、置顶、全局背景与透明度原样保留 |

组件体系：WorkspaceTab、DenseTaskRow、DocumentPane、FocusDock、StatusStrip、InspectorRow、MediaGrid、FeedbackLine。单独定义文字、背景、状态、选区、代码块、表格和弹层色值，避免只改窗口底色却保留浅色编辑器菜单。

## 反馈与可访问性

“保存中 / 已保存 / 保存失败”固定位置，不依靠闪动提示。焦点边框使用柔和青绿，选中行同时具有左边界。危险操作采用文字与确认，颜色不可充当唯一提示。正文仍为 14 DIP，支持 Windows 文本缩放后重新排版。

正在专注时，显示稳定的计时数字与任务名；暂停显示文字状态而非仅换按钮。正计时不显示百分比，本轮番茄进度也不与今日累计时间混用。深色不会自动降低内存或 CPU；性能取决于原生布局、浏览器生命周期及资源缓存。

## 适用与取舍

适合长时间使用便签、学习技术资料、计时与笔记来回切换的用户。它最大限度减少任务、阅读和计时之间的上下文切换，也最容易让应用像一套成熟的桌面工作工具。

设计判断：美观 4/5、可用性 4.5/5、维护便利 3/5、业务适配 4.5/5。主要成本是深色跨 WPF、Vditor、日历和弹层的一致性；透明背景上的文字也需更细致验证。用户早期的“可爱”偏好在本案中较弱，宜通过图标品牌和个人背景保留个性，不增加装饰。

评审时重点看：常驻专注区域是否值得占空间，深色是否适合白天使用，较紧凑的任务列表是否舒适。
