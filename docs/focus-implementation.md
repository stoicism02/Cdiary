## 已实现

- FocusStore：在同一 SQLite 数据库新增专注会话与设置；会话保存有效时间片段与任务标题快照。
- 会话 payload 为版本化更新的 JSON，索引列单独保存任务、状态和起始时间；单条原子写入保证状态与片段一致。
- 唯一部分索引阻止两个未结束会话；乐观版本检查阻止旧实例覆盖已恢复的会话。
- FocusService：番茄钟、正计时、短/长休息，暂停、恢复、结算、检查点及完成事件。
- 单调时钟计时，截止后封顶；中断恢复最后检查点并暂停，休息不计入投入时间。
- FocusStatistics：按指定时区拆分跨日时间片段。
- FocusRuntime：30 秒检查点或截止时间唤醒，锁屏/睡眠暂停，退出保存；等待 App 接入。
- 不存在每秒数据库写入或后台绘制循环。

- 颜色：暖纸 #FFFBEA、正文 #725D42、辅助字 #99886E、薄荷 #19BCAE、分隔 #DDD3B9。
- 字体沿用 Microsoft YaHei UI；正文左对齐，主计时区居中，时长数字采用等宽数字排版。
